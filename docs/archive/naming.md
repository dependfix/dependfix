# 项目命名方案

> 编制日期：2026-07-26
> 范围：项目名、npm 包名、GitHub 仓库名、域名。不涉及商标注册建议（需咨询专业人士）。

---

## 1. 命名原则

| 原则 | 说明 |
|------|------|
| **简短可拼写** | 英文母语者能读，非母语者也能拼出来 |
| **与能力关联** | 名字能让人联想到"依赖/安全/修复" |
| **npm 可用** | 包名未被占用（尤其不能与活跃的现有包冲突） |
| **域名可用** | `.dev` / `.io` / `.com` 至少一个能注册 |
| **GitHub 搜索不混淆** | 搜名字不会出来一堆无关项目 |
| **中文友好** | 没有中国人读不准的音节组合 |

|------|:---:|:------:|:-----:|:-----:|------|
| **dependfix** | ✅ 可用 | ✅ 可用 | ✅ 可用 | ✅ 可用 | 语义直白，"依赖修复"，易理解 |
| **fixdep** | ✅ 可用 | ✅ 可用 | ✅ 可用 | ❌ 已注册 | 简短（6 字符），但 .com 被占 |

## 3. 综合推荐

### 🥇 首选：`dependfix`

```
npm:   dependfix          ✅ 可用
.dev:  dependfix.dev      ✅ 可注册
.io:   dependfix.io       ✅ 可注册
.com:  dependfix.com      ✅ 可注册
GitHub Action 名称:       dependfix-action
CLI 命令:                 npx dependfix
```

**理由：**
- 语义最直白：developer 看到就知道是"dependency fix"
- 所有主流域名全部可用（.dev /.io /.com）
- npm 包名干净
- 易于组成生态：`@dependfix/cli`、`@dependfix/core`、`dependfix-action`
- 中文语境："依赖修复" + "depend fix" 联想自然

**关键词抢占策略：**
- GitHub Marketplace: `dependfix` (唯一匹配)
- npm: `dependfix`
- SEO 关键词: "dependfix", "dependfix github action", "dependfix security"

### 🥈 备选：`secbump`

```
npm:   secbump            ✅ 可用
.dev:  secbump.dev        ✅ 可注册
.io:   secbump.io         ✅ 可注册
.com:  secbump.com        ✅ 可注册
GitHub Action 名称:       secbump-action
CLI 命令:                 npx secbump
```

**理由：**
- 短小精悍（6 字符），比 dependfix 更短
- "Security Bump" 概念独特，有技术感
- 所有域名可用
- 容易做 logo（盾牌 + 上升箭头）

### 🥉 备选：`guardup`

```
npm:   guardup             ✅ 可用
.dev:  guardup.dev         ✅ 可注册
.io:   guardup.io          ✅ 可注册
CLI 命令:                  npx guardup
```

**理由：**
- 动词短语，有行动感和守卫感
- 唯一性高，搜"guardup"没有干扰结果
- 适合做安全主题的品牌

## 7. 域名注册成本分析

### 7.1 各 TLD 价格（Cloudflare Registrar 成本价）

Cloudflare Registrar 提供不加价的成本价注册和续费，是最推荐的开发者域名的注册商。以下为主要 TLD 的年费估算：

| TLD | 首年 ~年费 | 续费 ~年费 | 特点 | 适用场景 |
|-----|:---------:|:---------:|------|---------|
| **`.dev`** | **~$12** | **~$12** | Google 运营，强制 HTTPS，技术社区识别度高 | **首选主域名** |
| **`.com`** | **~$10** | **~$10** | 最通用，用户习惯输入 `.com` | **品牌保护 + 转发** |
| **`.io`** | **~$35-45** | **~$45-55** | 初创/技术社区流行，续费贵 | 可选主域名或保护 |
| **`.app`** | ~$12 | ~$12 | 强制 HTTPS，适合应用类项目 | 备选保护 |
| **`.tools`** | ~$15 | ~$15 | 描述性强 | 备选保护 |

> 数据来源：Cloudflare Registrar 成本价，实际价格以注册时为准。`.io` 为 ccTLD，registry 费用较高，价格波动大。

### 7.2 各候选名称 × 域名组合成本估算

以 `dependfix` 为例（最推荐名称），Cloudflare 注册：

| 域名 | 年费 | 注册 1 年 | 注册 3 年 | 注册 5 年 |
|------|:---:|:---------:|:---------:|:---------:|
| **dependfix.dev** ✅ 主站 | ~$12 | ~$12 | ~$36 | ~$60 |
| **dependfix.com** ✅ 保护 | ~$10 | ~$10 | ~$30 | ~$50 |
| **dependfix.io** 备选 | ~$45 | ~$45 | ~$135 | ~$225 |
| **小计（主站 + 保护）** | | **~$22** | **~$66** | **~$110** |
| **小计（全注册）** | | **~$67** | **~$201** | **~$335** |

> `dependfix.com` 只做 301 转发到主站，不需要续费高级 DNS 套餐。Cloudflare 自带 Free DNS。

### 7.3 注册策略推荐

#### 必注册（主域名）
| 优先级 | 域名 | 理由 | 估算年费 |
|:-----:|------|------|:-------:|
| P0 | **`dependfix.dev`** | 主站域名。`.dev` 是开发者社区首选 TLD，强制 HTTPS，品牌识别度高 | ~$12 |
| P0 | **`dependfix.com`** | 品牌保护。防止 typosquatting / 竞品抢注，301 转发到 `.dev` | ~$10 |

#### 防御性注册（降低风险）
| 优先级 | 域名 | 理由 | 估算年费 | 风险等级 |
|:-----:|------|------|:-------:|:--------:|
| P1 | **`dependfix.io`** | 如果未来想做 startup 风格品牌，`.io` 是备选主域名。**但续费贵** | ~$45 | 中 |
| P1 | **`secbump.dev`** | 如最终选用 dependfix 但 secbump 是第二候选，防止被占 | ~$12 | 低 |
| P2 | **`secbump.com`** | 同上，com 版本保护 | ~$10 | 低 |
| P2 | **`trydependfix.com`** | 营销落地页常用模式 | ~$10 | 低 |
| P2 | **`dependfix.app`** | 防止应用商店关联域名被占 | ~$12 | 低 |

**年域名总成本预估（P0 + P1 防御）：~$79/年**，相当于一杯咖啡的价格。

### 7.4 恶意抢注风险评估

| 风险 | 概率 | 影响 | 是否需要防御 |
|------|:---:|:---:|:-----------|
| 竞品抢注 `.com` | 🟡 中 | 🔴 高（品牌混淆，用户流向竞品） | **是，尽快注册** |
| 域名炒卖者抢注 | 🟡 中 | 🟡 中（可能高价转卖） | 建议先注册 |
| typosquatting | 🟢 低 | 🟡 中 | 可通过 Cloudflare 免费防护 |
| 同名 npm 包被占 | 🔴 高 | 🔴 高 | **立即注册 npm 包名**（免费） |

### 7.5 省钱建议

| 建议 | 节省 |
|------|:----:|
| 使用 Cloudflare Registrar 注册所有域名（不加价，续费=首年） | 比 Namecheap 省 10-50%/年 |
| `.dev` + `.com` 为主，暂不注册 `.io`（除非品牌需要） | 省 ~$45/年 |
| 先注册 1 年，品牌稳定后再延长至 3-5 年 | 首年只需 ~$22 |
| npm 包名立刻注册（免费） | — |

### 7.6 关键行动期限

| 动作 | 建议时间 | 说明 |
|------|---------|------|
| 注册 npm 包名 | **立即**（免费，先占坑） | 在确定名称后立刻注册，防止被占 |
| 注册 `{name}.dev` | 确定名称后 24h 内 | 主域名，建议通过 Cloudflare 注册 |
| 注册 `{name}.com` | 与 `.dev` 同时 | 品牌保护，成本极低 |
| 创建 GitHub 组织 | 与域名同时 | 避免组织名被占 |
| 决定是否注册 `.io` | 1 个月内 | 续费贵，可延迟决策 |

## 8. 下一步

1. 确定选用名称
2. 注册 npm 包名（立即，免费）
3. 通过 Cloudflare Registrar 注册 `{name}.dev` + `{name}.com`（~$22/年）
4. 创建 GitHub 组织，迁移仓库
5. 更新 README 和所有文档中的项目名称
6. 注册 GitHub Marketplace 条目（`{name}-action`）
7. 可选：注册防御性域名（`.io`、备选名称域名）
