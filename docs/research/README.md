# 调研文档目录（Research）

> 本目录存放**调研 / 研究类文档**（竞品分析、技术调研、决策依据等），
> 与 [design](../design/packages/index.md)（设计落地）和 [plan](../plan/todo.md)（规划）分离。

**规范定义**：调研文档的命名规范、内容结构与处置流程统一定义在 [文档规范 §5.1](../standards/documentation.md#51-调研文档规范docsresearch)。

## 简要约定

- 文件名：`{YYYY-MM-DD}-{topic-slug}.md`（同日多次调研追加 `-v{n}`）
- 调研完成后按"落地 → 保留 → 归档/删除"处置，并在文档末尾注明去向
- 当前文档索引见 [VitePress 侧边栏](../.vitepress/config.ts) 的 research 分组
