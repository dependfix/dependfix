# 文档规范

本文档从 momei 继承并适配，定义 dependfix 项目的文档编写标准。

## 1. 文档结构

```
docs/
├── index.md                 # 文档站首页
├── design/                  # 架构、数据模型、安全设计
├── guide/                   # 快速开始、配置、技术栈
├── plan/                    # todo、roadmap
├── research/                # 竞品分析、策略
├── archive/                 # 历史文档归档
└── standards/               # 项目规范（本目录）
```

## 2. Markdown 约定

- 单个 H1 标题，层级不跳级（`#` → `##` → `###`）
- 中文语境统一使用全角括号 `（）`
- 代码块标注语言：` ```typescript `
- 图表优先 Mermaid
- 关键信息使用 VitePress 容器：`::: info` / `::: warning` / `::: danger`

## 3. 文档行数阈值

| 文档 | 健康窗口 | 强制分片 |
|------|---------|---------|
| README | <= 300 行 | > 400 行 |
| `roadmap.md` | <= 800 行 | > 900 行 |
| `todo.md` | <= 500 行 | > 600 行 |
| `todo-archive.md` | <= 500 行 | > 700 行 |

## 4. 事实源层次

| 层级 | 文件 | 职责 |
|:----:|------|------|
| L0 | `AGENTS.md` | 项目级 AI 行为准则 |
| L1 | `docs/standards/*.md` | 专项规范 |
| L2 | `docs/design/*.md` | 架构与设计 |
| L3 | 平台适配文件 | 工具差异 |

## 5. 文档同步原则

- 代码变更时同步更新相关文档
- 路径、链接、命令必须真实可用
- 设计文档先于实现落盘
