# 外部 Skills 准入清单

本文档汇总当前允许作为"外部参考 skill"使用的候选项，说明来源、同步地址、更新频率与失效处理。

> 外部 skill 只作为参考来源或调用入口，不进入项目内部库存。

## 准入规则

1. 外部 skill 必须有清晰来源，不得伪装成项目内部定义。
2. 外部 skill 只能作为参考，不得直接复制为长期镜像。
3. 当外部 skill 与项目规范冲突时，优先遵循本项目规范。
4. 若某外部 skill 连续多次被依赖且需要项目特化约束，应评估是否转内部化。
