# 测试规范

本文档从 momei 继承并适配，定义 dependfix 项目的测试标准。

## 1. 测试框架

- 单元/集成测试：Vitest
- E2E：Playwright（平台阶段启用）

## 2. 测试组织

- 单元测试与源文件同目录：`src/utils/index.spec.ts`
- 集成测试：`tests/` 目录
- 测试文件命名：`*.spec.ts`（单元） / `*.test.ts`（集成） / `*.e2e.test.ts`（E2E）

## 3. 测试分级

| 级别 | 适用 | 命令 |
|------|------|------|
| 定向测试 | 日常开发 | 指定文件运行 |
| 全量测试 | 提交前 / CI | `pnpm test` / `pnpm -r test` |
| Review Gate | 阶段归档前 | `pnpm test` + typecheck + lint |

## 4. 覆盖率目标

| 范围 | 目标 |
|------|:----:|
| 整体 | >= 60% |
| 核心模块 | >= 80% |

## 5. 测试原则

- 测试聚焦业务行为，而非实现细节。
- 至少覆盖主流程、失败路径、边界条件。
- mock 不掩盖真正的集成风险。
- 测试失败时先解释根因，再决定改代码还是改测试。
